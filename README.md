# Fruit Blaster 

A Python game made using Pygame where the player controls a slingshot and shoots stones at falling fruits.

## Features
- Slingshot movement
- Stone shooting mechanic
- Falling fruits
- Score and high score system
- Lives system
- Main menu

## Controls
- Left Arrow → Move Left
- Right Arrow → Move Right
- Space Bar → Shoot

## Technologies Used
- Python
- Pygame
